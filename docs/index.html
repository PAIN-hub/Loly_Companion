Key Capabilities

Built specifically for the agentic coding era.

Everything you need to monitor, control, and collaborate with autonomous AI agents.

👁️

Cursor-Tracking Mascot

Loly's pupils calculate exact angular vectors to watch your mouse cursor smoothly across your screen, reacting to your focus and tasks.

⚡

In-Pill Approvals

Review CLI commands and file diffs without switching terminals. Click Allow, Deny, or Always directly from your screen notch.

✨

Google Gemini Integration

Instant streaming chat powered by Gemini 2.5 Flash, safety command analysis, and drag-and-drop code inspection.

🎵

Procedural Lo-Fi Music

4 built-in focus soundscapes generated directly via Web Audio API. Zero external MP3 files, zero latency, lightweight ambient flow.

🔒

Local SQLite Audit Log

Every agent step, command, approval decision, and chat message is logged in local SQLite (`~/.loly/loly.db`). 100% private.

🔌

Universal Hook Bus

Connects with any agent via Unix domain socket (`/tmp/coucou.sock`), Windows named pipes, or simple HTTP POST requests.

Developer Setup

Run with Node.js in 3 Steps

Clone the repository and run Loly directly on your machine.

bash — Terminal 
# 1. Clone the repository
git clone https://github.com/PAIN-hub/Loly_Companion.git
cd Loly_Companion

# 2. Install dependencies
npm install

# 3. Start the background server
npm start

# (Optional) Launch the transparent floating Electron island
npm run electron

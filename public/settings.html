Supported Voice Commands
  • "Hey Loly" / "Coucou Loly" — Wakes the island and prepares to listen
  • "Hey Loly, open settings" — Opens this settings window
  • "Hey Loly, play music" / "pause music" — Controls internal audio tracks
  • "Hey Loly, hide" / "collapse" — Retracts the notch island
  • "Hey Loly, agent mode" — Toggles autonomous coding agent mode
  • "Hey Loly, [your prompt or coding question]" — Directly asks Loly with speech feedback
